🔧 System Components

Core Files:

  • temporal_neuron.py - Temporal neuron classes with continuous dynamics
  • foveal_retina.py - Retina with eccentricity-based distribution
  • bipolar_cells.py - Bipolar layer with center-surround receptive fields
  • webcam_input.py - Real-time camera input (real or simulated)
  • visualization_3d.py - Interactive 3D visualization system
  • temporal_server.py - Flask server with temporal updates

Legacy Files (Original Simple System):

  • neuron.py - Basic neuron classes
  • retina.py - Uniform retinal layer
  • server.py - Simple Flask server
